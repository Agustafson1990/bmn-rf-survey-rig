# Code of Conduct

This is a small operations repo run by a working MSP, so the rules are short.

## The rules

1. **Be useful.** Help, ask, file a bug, suggest a fix — all welcome.
2. **Be civil.** Disagree with the work, not the person. No personal attacks,
   no slurs, no harassment.
3. **Stay on-topic.** Repo issues are for repo concerns. Off-topic threads
   get politely redirected, then closed.
4. **Respect confidentiality.** Don't share customer names, IPs, credentials,
   serials, or any data that could identify a BMN client. Redact before
   posting logs.

## Enforcement

Issues, PRs, and comments that break these rules will be edited or removed.
Repeat offenders will be blocked from the repo. There's no appeals process —
this is a small project, and time spent on enforcement is time not spent on
the work.

## Reporting

If something looks off and you'd rather not raise it in a public issue,
email `aaron@bytemenetworks.com`. Reports are read; they may not be
publicly acknowledged.
